### Research interests

- **Integrated Sensing and Communication (ISAC) for 6G** — using one waveform to both carry data and see the scene
- **AI for wireless and radar signal processing** — learned front ends where closed-form estimators break down
- **Micro-Doppler based sensing** — reading motion signatures out of the returned spectrum

### How I work

Most of these started as something I wanted to exist and then wrote end to end — the data source, the background job, the UI, the release checklist. They are where I practice system design, scheduling, and testing outside of coursework, so the parts that usually get skipped in a class project are the parts I keep.
